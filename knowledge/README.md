# Startup knowledge base

A curated, attributed knowledge base shared by every skill in this repository. It contains **original summaries and analytical frameworks**, not reproductions of essays, books or articles. Each file links to its primary sources so readers can go to the original.

## Source policy

1. **Attribute everything.** Every file lists its sources, the URLs, the date they were checked, and whether the file is an *attributed summary* (of someone else's ideas) or *original analysis* (this project's synthesis).
2. **Paraphrase, don't copy.** Quotations are short, marked and attributed. No essay, article or book is stored verbatim.
3. **State the verification level.** Front matter `verification:` says how the content was checked:
   - `read-at-source`: the page text was retrieved and read on the check date.
   - `url-verified`: the URL and title were verified on the check date. The summary draws on the published text, which was not re-read in full during this session.
4. **Don't overstate authority.** These files summarise *public* guidance. They do not represent any firm's private investment process, and the skills must never claim that they do.
5. **Re-check periodically.** Run `python3 scripts/check_links.py` to re-verify URLs and titles.
