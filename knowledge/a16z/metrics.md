# Metric definitions investors expect (paraphrased)

| Metric | Correct usage | Deck / proposal rule in Startup Skills |
|---|---|---|
| Bookings vs revenue | Contract value vs recognised revenue | Label which one is shown |
| Recurring vs total revenue | Recurring is valued more | Show the split |
| Gross profit | Revenue minus delivery cost | Use for LTV, not revenue |
| TCV vs ACV | Whole contract vs 12 months | Label it |
| LTV | Present value of future *net profit* | Our calculator uses gross-margin LTV and says so |
| GMV vs revenue | Volume through the marketplace vs the fees kept | Never call GMV "revenue" |
| Deferred revenue, billings | Cash collected before it's earned | Report only from accounts |
| CAC | Fully loaded. Paid CAC is more revealing than blended | Show paid and blended separately |
| Active users | Define "active" explicitly | Definition required in the evidence entry |
| MoM growth | Use CMGR for comparison | Show the base and the period |
| Churn | Gross vs net revenue churn | Label it |
| Burn | Net burn drives runway | The model reports net burn |
| Downloads | A vanity metric | Never a headline metric |
| Cumulative charts | Always go up | Blocked as "growth" charts |
| Chart tricks | Unlabelled axes, % without absolutes | Values labelled; base shown |
| Order | Size before growth | Metrics slide shows size, then rate |
