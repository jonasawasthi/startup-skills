# Fundraising readiness assessment

Rate each dimension **ready / partly / not ready**, with evidence. The output is a readiness profile with gaps, not a single score.

| Dimension | Ready looks like | Evidence |
|---|---|---|
| Story clarity | One-sentence description; insight; why now | Deck cover and the seven questions |
| Progress | Shipped product + usage or revenue growth, or credible technical milestones | Ledger (verified/reported) |
| Market | Bottom-up sizing with sources | market-size output |
| Team | Founder–market fit; committed founders; clean equity | team.md |
| Plan | Milestones the round buys; the raise amount justified by the plan | financial model, roadmap |
| Materials | Deck (long and short), one-pager, model, data room | Generated artifacts |
| Legal and corporate | Entity, cap table, IP assignment, jurisdiction-appropriate instrument | Founder-provided documents |
| Diligence hygiene | Metrics definitions, contracts, compliance status | Data room checklist |
| Investor pipeline | A target list with thesis fit and warm paths | investor-fit outputs |

## Stage expectations (heuristics; vary by market and year)

- **Idea / pre-seed:** team, insight, early user evidence, prototype.
- **Seed:** a launched product, early retention, early revenue or strong usage growth, an initial GTM signal.
- **Series A:** repeatable acquisition, retention, unit economics trending well, a clear path to scale.
- **Growth:** efficient growth at scale, multiple channels, a path to profitability.

Never state that a company "will" raise. Assess readiness and gaps only.
