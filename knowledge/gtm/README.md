## Notes on sources

- **OpenView Partners** has wound down, and its blog URLs now redirect to the homepage. The files cite Internet Archive copies, and the link checker verifies the archived titles.
- **YC Library** entries are mostly videos. Where a file says `url-verified (description read)`, the summary relies on the library's published description and the speaker's known topic, and the talk was not re-watched.
- **Books** (Dunford's *Obviously Awesome*, Moore's *Crossing the Chasm*, Fitzpatrick's *The Mom Test*, Chen's *The Cold Start Problem*) are summarised at the level of their publicly described ideas. No text is reproduced.
