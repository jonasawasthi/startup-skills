# outputs/

Generated artifacts go here, one folder per startup:

```
outputs/<startup>/
  startup-profile/      shared profile + evidence ledger
  startup-analysis/     idea evaluation
  business-proposal/    proposals and business plans
  investor-pitch/       decks, narrative, Q&A, missing information
  fundraising/          readiness, investor research, outreach
  financial-model/      XLSX models and summaries
  research/             research briefs and bibliographies
```

Everything except this README is **gitignored**. Startup analyses contain private information and must not be committed to a public repository. The fictional example in `examples/fieldnote/` shows the formats.
