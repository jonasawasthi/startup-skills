# Scoring rubric (qualitative)

Rate each dimension. A rating summarises evidence. It is **not** a probability and must never be added up into one.

| Rating | Meaning |
|---|---|
| **Strong** | Behavioural or verified evidence supports it; few open questions |
| **Adequate** | Plausible with some evidence; important questions remain |
| **Weak** | Evidence points against it, or a critical gap exists |
| **Unknown** | Not enough evidence to judge. This is a task, not a judgement |

Each rating carries a **confidence** (high / medium / low), meaning *how confident we are in this rating given the evidence*.

| Dimension | Strong looks like |
|---|---|
| Problem severity | Frequent, costly, with current spending on workarounds |
| Customer clarity | Narrow ICP with a reachable early-adopter group |
| Market | Bottom-up SAM large enough for a venture outcome (or the right size for the founder's goal) |
| Timing | A specific recent change enables the solution |
| Differentiation | A 10× improvement on a criterion customers use |
| Business model | Unit economics work under conservative assumptions |
| Distribution | A repeatable channel with CAC evidence, or a built-in loop |
| Defensibility | A named moat with a path to evidence |
| Founder–market fit | Domain insight + customer access + shipping record |
| Execution risk | Scope achievable with the current team and capital |

## Overall verdict (choose one; never a percentage)

- **Pursue**: critical dimensions strong or adequate; validate the remaining unknowns quickly.
- **Pursue with changes**: promising, but one critical dimension needs a pivot (segment, model or channel).
- **Validate before building**: too many critical unknowns; run the experiments first.
- **Do not pursue as framed**: a critical dimension is weak, with evidence.

Always add: *"This assessment reflects the evidence available on <date>. It is not a prediction of success."*
